# Binary Builders

Vite single-page site. `npm run dev`, `npm run build` → `dist/`.

Visual work (UI, layout, motion, color, type, copy) follows [DESIGN.md](DESIGN.md). Read it before changing `index.html`, `src/styles.css`, `src/field.ts`, or the banner files. Do not invent a second system.

Live tokens live in `src/styles.css`. `themes/` is the retired Hugo site; ignore it for new work.

The old `STYLE_GUIDE.md` (Inter, `#007AFF`, utility classes) is not this site.
